LEARN BOOLEAN ALGEBRA

Boolean Algebra Laws

10 FUNDAMENTAL LAWS

Explore the fundamental laws of Boolean algebra used to simplify logical expressions and design digital circuits.

Operator Notation

+ OR operation
. AND operation
' NOT operation
0 / 1 False / True
LAW 01

Identity Law

A + 0 = A
A . 1 = A

OR with 0 and AND with 1 leave the original variable unchanged.

Example B + 0 = B
LAW 02

Null / Domination Law

A + 1 = 1
A . 0 = 0

OR with 1 always gives 1, while AND with 0 always gives 0.

Example B . 0 = 0
LAW 03

Idempotent Law

A + A = A
A . A = A

Applying the same variable twice produces the same variable.

Example B + B = B
LAW 04

Complement Law

A + A' = 1
A . A' = 0

A variable ORed with its complement gives 1; ANDing them gives 0.

Example B + B' = 1
LAW 05

Involution Law

(A')' = A

Taking the complement twice returns the original variable.

Example ((B')') = B
LAW 06

Commutative Law

A + B = B + A
A . B = B . A

Changing the order of variables does not change the result.

Example A + B = B + A
LAW 07

Associative Law

(A + B) + C = A + (B + C)

(A . B) . C = A . (B . C)

Changing the grouping of the same operation does not affect the result.

Example (A + B) + C = A + (B + C)
LAW 08

Distributive Law

A . (B + C) = A.B + A.C

A + (B.C) = (A+B).(A+C)

An operation can be distributed over another using Boolean algebra rules.

Example A.(B+C) = A.B + A.C
LAW 09

Absorption Law

A + A.B = A
A . (A+B) = A

A larger expression can be reduced to the absorbing variable.

Example A + A.B = A
LAW 10

De Morgan's Laws

(A.B)' = A' + B'

(A+B)' = A'.B'

Complementing an expression changes AND to OR, or OR to AND, while complementing each variable.

Example (A.B)' = A' + B'

QUICK REVISION

Remember These Three Rules

  • Identity: A + 0 = A
  • Complement: A + A' = 1
  • De Morgan: (A+B)' = A'.B'
